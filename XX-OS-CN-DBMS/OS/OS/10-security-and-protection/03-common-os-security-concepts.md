# Common OS Security Concepts

### ASLR
Randomizes locations of memory regions to make exploitation harder.

### NX/DEP
Marks memory regions as non-executable where possible, reducing code-injection opportunities.

### Privilege separation
Run components with only required privileges.

### Sandboxing/isolation
Restrict what a process can access even if compromised.

### Secure boot
Uses a chain of trust to verify boot components before execution.

These are defense mechanisms, not guarantees of security by themselves.

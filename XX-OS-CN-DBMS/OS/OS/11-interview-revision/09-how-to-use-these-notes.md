# How to Use These Notes

The goal is not to memorize every paragraph. For each P0 topic, you should be able to reconstruct the mechanism from first principles.

## 5-minute loop

1. Read the definition.
2. Close the notes and explain the mechanism aloud.
3. Draw the diagram from memory.
4. Solve the small example.
5. Answer one interviewer follow-up: **why, trade-off, or what happens next?**

## When a concept still feels weak

Use the external resources in `README.md` selectively:

- OSTEP → conceptual understanding
- xv6 → implementation intuition
- Linux man-pages → exact API behavior
- Linux kernel docs → production-kernel depth

## Interview standard

You are ready when you can answer:

> **What is it? → Why do we need it? → How does it work? → Give me a tiny example → What is the trade-off? → What is it commonly confused with?**

If you can only recite the definition, the concept is not interview-ready yet.

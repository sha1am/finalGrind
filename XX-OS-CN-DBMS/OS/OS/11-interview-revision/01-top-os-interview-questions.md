# Top OS Interview Questions

## Must-answer questions

1. What is an OS and why do we need it?
2. Kernel vs OS?
3. User mode vs kernel mode?
4. What is a system call?
5. Program vs process?
6. Process vs thread?
7. What is a PCB?
8. Explain a context switch.
9. What happens during `fork()`?
10. `fork()` vs `exec()`?
11. Zombie vs orphan?
12. FCFS vs SJF vs RR?
13. Preemptive vs non-preemptive scheduling?
14. What is a race condition?
15. Mutex vs semaphore?
16. What is a deadlock?
17. Four necessary conditions for deadlock?
18. Deadlock vs starvation?
19. Paging vs segmentation?
20. What is a TLB?
21. What is a page fault?
22. What is virtual memory?
23. What is thrashing?
24. FIFO vs LRU vs optimal replacement?
25. What is an inode?
26. Hard link vs soft link?
27. Interrupt vs system call?
28. What is DMA?
29. Blocking vs non-blocking I/O?
30. How does `read()` of a file broadly work?

## Strong follow-ups

- Why can a syscall be expensive?
- Why are TLB misses costly?
- Why can a context switch hurt cache locality?
- Why can a mutex deadlock?
- How does lock ordering prevent deadlock?
- Why does LRU exploit locality?
- Why can a deleted file still occupy disk space?
- Why do servers use event loops?
- Why are containers not VMs?

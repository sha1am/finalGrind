If you want **one resource only**, I'd choose **OSTEP** first. It is particularly good because it organizes OS around **virtualization, concurrency, and persistence**, and generally teaches by starting with a problem and building the mechanism that solves it. 

Then use **MIT xv6** when you want to go from “I understand the concept” to “I understand how an OS implements it.” MIT explicitly uses xv6 to teach virtual memory, threads, context switches, interrupts, system calls, IPC, coordination, and software/hardware interaction.
